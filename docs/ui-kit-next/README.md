# UI kit 2 drafts

Design material for the UI standard (`docs/ui-standard.md`). Nothing here is loaded by a module.

- `ag-ui-next.draft.css`: proposed additions to `styles/ag-ui.css` (shipped in the shared kit release, `docs/ui-pass-plan.md` PR 2).
- `skins-next.draft.css`: matching rules for Manager's Stone Tablet and Tome Pages skins.
- `build-style-guide.mjs`: builds `style-guide.html` from the real kit, skins, skin token tables and Renown CSS. Run `node docs/ui-kit-next/build-style-guide.mjs` after changing any of them.
