## Goal
Ship the Rounded Compact base look (direction D), the Compact/Comfortable size sets and the kit-2 parts to all ten modules in one coordinated release. Promote one shared dialog helper. Add the drift lint in ratchet mode. No module's own layout is reworked here; that happens in the module passes.
